Run /harvest-check first. Then `npm run cropping -- harvest "<crop>" --tonnes=<t> --moisture=<%> --destination="..." --reference=<load or docket> --date=YYYY-MM-DD`. Add `--final=no` when more loads are coming. A WHP HOLD or HOLD UNKNOWN refusal is the point: tell the operator the clear date or the record to fix. Never work around it.
